Getting Started

SpendSift API

Local-first personal finance REST API. The backend runs on 127.0.0.1:8765; every request is loopback-only. All monetary amounts are decimal strings — no floats anywhere in the API surface.

Single-user, no auth. The API has no authentication layer — it binds to loopback only. All writes snapshot the journal (storage/journal/ → storage/snapshots/) first, so every destructive call is rollback-safe. 

# Quick health check
curl http://127.0.0.1:8765/api/health

# Returns
{"status": "ok"}
Getting Started

Error Envelope

All coded errors return a uniform JSON envelope. The code field is machine-readable; detail and description are identical and user-displayable.

{
  "code":        "E1015",
  "status":      422,
  "detail":      "The AMFI price feed returned no schemes while funds are held.",
  "description": "The AMFI price feed returned no schemes while funds are held.",
  "resolution":  "Cached NAVs kept; try refreshing later."
}
Prices / NAV

NAV Pipeline

Live NAV refresh from the AMFI NAVAll feed. Held funds = positive unit balance. Prices are stored in nav_history.parquet and written as price directives to journal/prices.beancount.

GET /api/prices/status Current NAV freshness — no network call
Parameters

None. Reads from the cache sidecar — honest after a reload.

{
  "as_of":    "2026-06-30",
  "source":   "fetched",   // "fetched" | "cached" | "offline" | "never"
  "priced":   [
    { "symbol": "MF122639", "name": "Parag Parikh Flexi Cap Fund - Direct Plan - Growth" },
    { "symbol": "MF120716", "name": "UTI Nifty 50 Index Fund - Direct Plan - Growth" }
  ],
  "unpriced": []
}
POST /api/prices/refresh Conditional-GET AMFI feed + write prices.beancount
Offline-safe. Returns the same shape as /status. A zero-scheme 200 response while funds are held raises E1015 and leaves the cache intact.
// Errors: E1014 (NAV store corrupt), E1015 (empty dump while holding)
{
  "as_of":    "2026-06-30",
  "source":   "fetched",
  "priced":   [{ "symbol": "MF122639", "name": "Parag Parikh Flexi Cap Fund..." }],
  "unpriced": []
}
POST /api/prices/backfill Pull historical NAV from mfapi.in for all ever-transacted funds
Fetches since the fund's earliest transaction. Skips funds already covered. 200ms rate-limit per fund. Errors are per-fund, non-fatal.
{
  "fetched":               2,
  "skipped_already_covered": 1,
  "skipped_errors":        [],
  "rows_added":            842
}

Import Pipeline

Import Pipeline

A multi-step flow: detect header → create template → classify → review candidates → edit → commit. Investments (Groww MF) go through a separate MF-scheme resolution step.

POST /api/import/detect Parse uploaded file, detect header row and column mapping
Request Body

Multipart form: file field with the CSV/statement file.

{
  "filename":    "HDFC_statement_Jun2026.csv",
  "fingerprint": "a3f8c2e1",
  "header_row":  0,
  "columns":    { "date": 0, "narration": 1, "amount": 4 },
  "preview":     [["01/06/2026", "UPI/Swiggy", "", "", "-420.00"]]
}
POST /api/import/classify Classify upload as bank statement or Groww investment file
Request Body

Multipart form: file + optional force_kind ("statement" or "investment").

Error Codes
